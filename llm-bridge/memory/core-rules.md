# Core rules (written by hand; the model reads these but never changes them)

- Early game (minutes 0-6): expand. Get a second refinery before attacking.
- If enemy units are near your ore, defend for a moment, then harass back.
- If the enemy is building a Singularity core (SGCOLO / SGNODE), switch to attack with target core. Nothing matters more.
- If you see more than 3 enemy aircraft or drones, build antiair until they are gone.
- If the enemy has many defences (pillboxes, Tesla coils, prism towers), build artillery.
- If a wave came back with less than a third of its value, defend and rebuild before the next one.
- With a big army and money banked, attack the enemy war factory first.
